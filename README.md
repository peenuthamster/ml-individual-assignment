# Machine Learning Individual Assignment

Workspace for the CSC61304 Machine Learning and Intelligent Systems individual assignment.

## Status

Dataset selection and project planning are in progress. No final dataset or model has been selected.

## Datasets under consideration

- [Richter's Predictor: Modeling Earthquake Damage](https://www.drivendata.org/competitions/57/nepal-earthquake/) — structured building data from Nepal.
- [16NepaliNews](https://github.com/sndsabin/Nepali-News-Classifier) — Nepali news articles for text classification.

Downloaded datasets and the assessment guidelines are kept locally and are not included in this repository. Obtain datasets from their original sources and follow the applicable terms of use.

Notebooks, experiments, and project documentation will be added after the project scope is selected.
